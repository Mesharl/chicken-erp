# Mobile workflows

Field staff need fast, low-friction capture.

## Priority flows
1. Record egg collection
2. Record mortality
3. Record feed issue or consumption
4. Record vaccination or treatment
5. Receive purchase into stock
6. Confirm sale or delivery

## Design rules
- Large tap targets
- Minimal required fields
- Offline-friendly outbox (planned)
- Clear success and error feedback
- Works on mid-range Android devices common in Kenya

The shell includes a bottom navigation bar for phones. Desktop uses the sidebar.
